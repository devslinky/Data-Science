# Data-Science
Repository containing Data Science Labs and Coursework 

Coursework includes 
- simple data cleaning, visualization and EDA tasks
- NLP including preprocessing (lemmatization/stemming, tokenization) and text analysis (Mutual Information, Entropy)
- Time Series Analysis (Autocorrelation, Correlation, Seasonality etc.)
- Geographic Data Analysis (Vector/Raster Data)
- Network Data Analysis (measures of centrality, network visualization)
